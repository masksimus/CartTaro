# Путь Арканов V5 — выпуск без изменения текущего приложения ВК

Текущий статус: **release candidate (не релиз)**. GitHub Actions: https://github.com/masksimus/CartTaro/actions/runs/41966763661 — 9/9 Android Playwright E2E, тестирование с PostgreSQL и регрессионные серверные тесты.

## Что готово
- `release/index.html`, `release/app.js`, CSS — пользовательский интерфейс без лабораторных надписей и поля тестировщика.
- Одна / три карты, оригинальные классические изображения Rider–Waite–Smith, серверное чтение истории и коллекции.
- `server/src/api-v2-handler.mjs`: отдельный публичный режим `public_game`; подпись запуска ВК, проверка app ID и времени, ровно одно получение ежедневной награды и карты за дату (уникальные ограничения и транзакции PostgreSQL).
- `preview/v2-pilot.html` остаётся доступен как отдельный тестовый интерфейс. `main` и публичный URL ВК не менялись.

## Включение — ТОЛЬКО после решения о релизе и нового VK Android UAT
1. Использовать **отдельную игровую PostgreSQL базу** с резервным копированием, а не текущую тестовую Neon-базу. Не переносить автоматически тестовые 10 кристаллов/аркан на публичных игроков.
2. В отдельном проекте/окружении Vercel, только после одобрения, задать:
   - `VK_PROTECTED_KEY` — секрет через Sensitive environment variable, не копировать в код/чат.
   - `DATABASE_URL` — адрес выделенной базы (секрет).
   - `TARO_V2_WRITES_ENABLED=true` **и** `TARO_V2_PUBLIC_GAME_ENABLED=true`.
   - `TARO_V2_TEST_ACCESS_PIN` **не задавать** в публичном режиме. При одновременном PIN и public флаге сервер преднамеренно остаётся `read_only`.
3. В отдельном VK developer URL указать `https://<test-host>/release/index.html` и выполнить полный тест с настоящим signed launch. Основной пользовательский URL не менять до окончательного подтверждения.
4. Проверить `GET /api/v2/status`: `mode=public_game`, `GET /api/v2/health`: `database=connected`, без раскрытия ключей.
5. Проверить в Android VK WebView: открытие, загруженные JPEG (без тестовых изображений), расклады 1/3, карта дня, 1 награда в сутки, повторный вход, отказ неверной подписи, смена суток UTC и повторный запрос без дублирования.
6. Только после полного UAT рассматривать основную публикацию и миграцию данных. При проблемах безопасный откат — отключить `TARO_V2_PUBLIC_GAME_ENABLED` и сделать новый deploy; сохранённые данные не удалять.

## Ограничения
- Нельзя считать этот код опубликованной игрой только потому, что CI зелёный: реальные операции выдачи наград в публичном режиме пока не проверены в VK Android.
- TTL подписи запуска 900 секунд; для новых операций после истечения требуется новый запуск внутри ВК.
- Реальные деньги, платежи, магазины и обмен кристаллов в этой версии **не предусмотрены**.
