# CartTaro V5 — юридические материалы для VK Mini Apps
**Статус:** проект документов. Не указывать ссылки на него как на утверждённую публичную политику. Дата подготовки: 05.11.2026.

## До публикации необходимо подтвердить
- ФИО/название и правовой статус оператора (ИП/самозанятый/организация/физическое лицо), применимый адрес/контакт, email для запросов.
- Географию обслуживания и место обработки пользовательских данных, ответственность Neon/Vercel, договорные основания и допустимость трансграничной передачи.
- Правовые основания обработки и сроки хранения для идентификатора ВК, прогресса, технических журналов.
- Порядок рассмотрения обращений и работающее удаление персональных данных; проверить его отдельными E2E.
- Фактический перечень и лицензирование иллюстраций Rider–Waite–Smith для каждой целевой страны.
- Требования и актуальные правила VK Mini Apps: https://dev.vk.com/ru/mini-apps-rules
- Модерацию ВК, включая изображения для каталога, описание, возрастные ограничения и способ связи.
- Политику конфиденциальности и пользовательское соглашение разместить по работающим публичным HTTPS-ссылкам, дать возможность прочитать до согласия; не подставлять вымышленные контакты.

## Данные, фактически обрабатываемые текущей версией V5
- Подписанные параметры запуска VK (проверяются сервером); идентификатор VK аккаунта в PostgreSQL.
- Начисленные виртуальные кристаллы, серия дней, дата последней награды, номер карты дня и открытые карты.
- Пользовательский свободный текст для гадания на сервер не передаётся, сервер выдаёт только случайные карты/толкования.
- Виртуальные кристаллы не обмениваются на деньги и не продаются.
- В текущем коде нет публичной функции удаления аккаунта и отдельного сохранения согласия; это **блокеры релиза**.

## Проект текста для последующей юридической проверки
**Политика обработки данных**: приложение «Путь Арканов» обрабатывает VK ID и данные игрового прогресса для предоставления персонализированного доступа и сохранения карт/кристаллов. Доступ к персональному прогрессу возможен только по подписанным параметрам запуска ВК. Данные находятся в базе PostgreSQL сервиса Neon, а пользовательские запросы обрабатываются через Vercel. Сведения об операторе, регионе хранения, сроках хранения, партнёрах-обработчиках, основаниях обработки, обращениях и удалении **нужно дополнить после проверки фактических условий**.

**Условия использования**: карты Таро предназначены для развлечения и размышления; не являются медицинской, юридической или финансовой консультацией. Кристаллы имеют только внутриигровое значение. Пользователь не должен передавать сторонним лицам подписанные параметры запуска приложения. Положения об ограничении ответственности, возрасте и применимом праве подлежат отдельной проверке.

## Технический релизный контроль
1. Действующая V4 и тестовая V5 остаются на разных базах; бэкап Neon уже проверен на отдельной ветке.
2. В V5 Production выдача наград должна оставаться выключена, пока `TARO_V5_PUBLIC_RELEASE_CONFIRMED` не равен `true`.
3. Публичный V5 нельзя подключать к VK без рабочего механизма запросов на удаление персональных данных и подтверждённого согласия.
4. Перед релизом отдельно проверить использование V5 для обычного VK пользователя, ошибки 401/403/503, повторные начисления и восстановление после перезапуска.
