# V5 — однопользовательская проверка ежедневных наград

Дата: 2026-11-05.
Цель: проверить реальные операции `claimDaily` и `drawDaily` с одним авторизованным разработчиком внутри ВК.

## Ограничения
- Только Vercel Preview-ветка `feature/tarot-v5-release-candidate`.
- Отдельная база `tarot_v5_game`; V4 `neondb` не менять и не переносить данные.
- `TARO_V5_UAT_MODE=true`, `TARO_V5_UAT_USER_IDS` хранится как sensitive server env.
- `TARO_V2_PUBLIC_GAME_ENABLED=true`; в рамках этого теста `TARO_V2_WRITES_ENABLED=true` только для V5 Preview.
- Подпись входа ВК проверяется перед разрешением аккаунта, серверный allowlist защищает все персональные операции. Другим аккаунтам — 403. Неподписанным — 401.
- Кристаллы условные, не деньги; нет платежей и вывода.
- GitHub `main`, основное приложение ВК и Production V4 не изменяются.

## Проверка на Android
1. Запустить приложение ВК со ссылкой разработки V5.
2. Проверить надписи `VK Bridge: подключён` и `Сервер: подпись проверена`; до теста баланс 0 и коллекция 0/22.
3. Нажать награду дня единожды: ожидается 10 кристаллов и серия 1 день.
4. Нажать карту дня единожды: открывается 1 из 22 и классическое изображение.
5. Повторные нажатия в те же UTC-сутки не должны менять данные.
6. Полностью закрыть и снова открыть через ВК; карта, баланс и коллекция сохраняются.
7. Проверить кнопку `Проверить сохранение карт и кристаллов`: только чтение, без начислений.
8. Перед общим релизом отключить Preview write-флаг либо оставить Preview закрытым; для публичной игры требуется отдельное одобрение.

Серверный `/api/v2/status` должен показывать `mode=public_game`, `rewardsEnabled=true` только в ветке Preview V5. Для обычной Production V4 режим `developer_pilot` не меняется.
