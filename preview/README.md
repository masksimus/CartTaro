# Карты Таро — визуальный предпросмотр без реальных данных

Это **только демонстрация внешнего вида** нового интерфейса. Не тестовая версия с авторизацией VK, не серверный баланс и не опубликованное приложение. Данные о кристаллах, картах и достижениях вымышлены; нажатия на кнопки меняют только текущий экран браузера и исчезают после обновления. Не выполняется ни одного сетевого запроса к VK и API.

## Открытие на телефоне

1. Скачайте артефакт **tarot-v2-https-preview-qa** из успешного GitHub Actions (файл `CartTaro_visual_demo.zip`) или готовый одиночный HTML.
2. Распакуйте ZIP в «Файлах» на Android.
3. Откройте `CartTaro_visual_demo.html` в Chrome / другом браузере через файловый менеджер.
4. Нажмите кнопки «Показать награду» и «Показать карту дня», проверьте колоду, задания и достижения. Никакие пользовательские данные не отправляются и не сохраняются.

При ограничениях на открытие локальных `file://` страниц используйте отдельный локальный HTTP-сервер или тестовый хостинг.

## Сборка

```bash
node preview/build-standalone.mjs
```

Создаёт `preview/dist/CartTaro_visual_demo.html` с inline CSS/JS и Content-Security-Policy, разрешающей **только точные SHA-256** встроенного кода и запрещающей сетевые подключения. Ни Vercel, ни внешний CDN для этого файла не требуются.

Автотесты: `tests/preview.spec.mjs` — 320, 360, 393 CSS px, два сценария на исходной статической странице и отдельный тест `file://` для автономной сборки.

## Следующий этап для полноценного теста VK

Исходный проверенный защищённый сервер находится в `server/` и `deploy/` ветки `feature/tarot-v2-staging`; реальная страница с VK Bridge — в `pilot/`. Для неё нужен отдельный защищённый HTTPS-хостинг с постоянной БД и непубличным VK protected key. **Не подменяйте URL рабочего VK-приложения** ради этого демо.

Vercel может размещать только это статическое визуальное демо. Сервер `node:sqlite` с постоянно сохраняемым файлом не следует разворачивать как Vercel Function: файловая система там не персистентна.

### Ограничения

- Никаких VK Bridge, рекламных событий, покупки товаров, выплат, логина или миграции старых VK Storage.
- Статическая визуализация не подтверждает работу API в приложении ВК.
- Автономная сборка не открывает настоящие аккаунты и не хранит персональные данные.
- Рабочая ветка `main` и приложение VK 54582199 не меняются.
