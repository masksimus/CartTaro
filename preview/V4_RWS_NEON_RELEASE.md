# CartTaro V4 — исторические карты + серверный прогресс Neon

Версия: `feature/tarot-v4-rws-neon-ui`.
Тестовое окружение: https://tarot-vk-uat-public-2026.vercel.app/v2-pilot.html
Исходная рабочая игра: https://masksimus.github.io/CartTaro/

## Что изменено

- 22 оригинальных изображения колоды Rider–Waite–Smith (1909), ранее проверенные и опубликованные в `art-preview/classic` на собственном GitHub Pages. Их номера строго соответствуют ID `0..21` в базе.
- Подписанные расклады 1/3 карты показывают целиком исторический рисунок, а перевёрнутая карта поворачивается на 180 градусов.
- Коллекция показывает живописные карты только для реально открытых ID. Закрытые карты не выдаются как открытые.
- В `GET /api/v2/progress` добавлено **неразрушающее** поле `dailyCardId` (число `0..21` или `null`); сервер получает его из существующей записи `tarot_v2_daily_cards`. Это не миграция и не дополнительный запрос на запись.
- Сохранённая карта дня снова показывается после каждого авторизованного запуска, даже если тестовый PIN не введён повторно.
- Исторические изображения загружаются с фиксированного публичного адреса, с `referrerPolicy=no-referrer`; разрешён только этот домен в CSP. Секреты и подписанные параметры ВК не уходят на сервер изображений.
- При сетевой ошибке картинки показывается символ-заглушка, а прогресс и награды остаются доступными.

## Безопасность и совместимость

- `main` (действующая игра) не изменён. Существующие данные VK Storage и Neon не мигрированы и не сброшены.
- В тестовой версии начисления по-прежнему ограничены сервером: действительная HMAC-подпись VK + код тестировщика в приватной переменной Vercel + один раз за сутки на пользователя.
- Расклады бесплатны и не изменяют таблицы наград/коллекции.
- Не размещайте в чатах или изображениях подписанный URL запуска ВК, ключ приложения, `DATABASE_URL` или код тестировщика.
- Для возврата старой тестовой версии восстановите предыдущее `READY` развёртывание Vercel проекта `tarot-vk-uat-public-2026`. База данных не затрагивается.

## QA и критерий допуска

GitHub Actions: https://github.com/masksimus/CartTaro/actions/runs/41837430515
Результат: **38/38 серверных и 45/45 мобильных тестов** на PostgreSQL 16 и Chromium Android (320, 360, 393 px).

Live Vercel: сайт `READY`; `GET /api/v2/health` сообщает `database: connected`, `progressReadReady: true`; `GET /api/v2/status` подтверждает разрешённый тестовый режим.
Реальная сессия владельца в VK WebView после публикации V4 всё ещё требует ручного подтверждения.

Для UAT: открыть VK Mini App ID 54582199 в режиме разработки по ранее указанной ссылке на `v2-pilot.html`. Проверить, что в коллекции сохранилась «Сила» (ID 8), баланс не изменился, в раскладах есть оригинальные рисунки. При повторном входе должна восстановиться та же сохранённая карта дня. **Картинка не является признаком начисления**: операции наград всегда требуют сервера.
