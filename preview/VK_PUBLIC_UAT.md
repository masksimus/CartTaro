# VK Mini Apps — отдельная публичная среда проверки входа

На Vercel создан самостоятельный проект `tarot-vk-uat-public-2026` (Hobby), не связанный с публичным визуальным демо `tarotpreview2026`.

**Тестовый URL:** https://tarot-vk-uat-public-2026.vercel.app/vk-login.html

**API статуса:** https://tarot-vk-uat-public-2026.vercel.app/api/vk/status

**Текущее состояние:** Vercel deployed READY; публичная страница доступна без Vercel Authentication; сервер показывает `configured:false`, поскольку в **НОВОМ проекте** ключ не настроен.

## Настройка без передачи секретов в чат

1. Открыть Vercel `tarot-vk-uat-public-2026` → Settings → Environment Variables.
2. Ввести `VK_PROTECTED_KEY` — официальный protected key **приложения VK №54582199**, тип **Sensitive**, окружение **Production**. В отличие от прежнего проекта это отдельный публичный *тестовый* проект; поэтому ключ здесь должен быть в Production. Не добавлять в GitHub, скриншот, комментарии, браузерную страницу или чат.
3. Сохранить и сделать **новый Production deployment только этого отдельного проекта**. После обновления `/api/vk/status` должен возвращать `configured:true`. Значение ключа в ответ не входит.
4. Проверять настоящий вход только с официального **URL для разработки** VK Mini App, не меняя основной/публичный URL приложения. Перед началом потребуется подтвердить, что VK позволяет назначить отдельный development URL для этого приложения.
5. Страница `/vk-login.html` сверяет VK Bridge user ID с подписанным launch user ID и отправляет HMAC лишь в same-origin API. При верной подписи выдаёт сообщение об успехе; никаких начислений или сохранения прогресса нет.

## Безопасность

Этот проект **публичный**, но API verify принимает только POST с подписанными параметрами VK и проверяет HMAC, app ID и время подписи на сервере. Никакой базы данных, баланса, платежей и персональных данных в ответе нет. Публичный route /api/vk/status содержит только флаг готовности; не содержит ключа.

Не меняйте `tarotpreview2026.vercel.app`, VK ID приложения, production URL действующей VK Mini App или основную ветку GitHub `main`. Если секрет ошибочно попал в чат/скриншот/репозиторий, его необходимо отозвать и заменить в настройках VK.

**Проверка:** 15/15 серверных и 30/30 мобильных тестов GitHub Actions, https://github.com/masksimus/CartTaro/actions/runs/41796921612. Реальный VK WebView UAT ещё не пройден.
